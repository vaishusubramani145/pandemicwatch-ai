Mathematical Foundations & Architecture

Core epidemiological formulas, ML feature engineering, and model validation specifications

1. SEIR Differential Equations

Captures transitions across susceptible, exposed, infectious, and removed populations:

dS/dt = -β(t)·S·I/N - ν·S dE/dt = β(t)·S·I/N - σ·E dI/dt = σ·E - γ·I dR/dt = (1-μ)·γ·I + ν·S

Where σ = 1/incubation period, γ = 1/infectious period, ν = vaccination rate, and β(t) is modulated by non-pharmaceutical interventions.

2. Dynamic Effective Reproduction Rₜ

Estimated using moving window intrinsic growth rate r and generation time interval Tc:

r = ln(Casest / Casest-w) / w Rₜ = exp(r · Tc)

Provides early warning before case surges materialize in hospital acute care admissions.

3. Machine Learning Forecasting Engine

Multi-horizon XGBoost & Random Forest time-series regression with rolling lags and external signals:

  • Lag Features: Lags at 1, 2, 3, 7, and 14 days.
  • Rolling Statistics: 7-day & 14-day rolling means and standard deviations.
  • Exogenous Variables: Test Positivity Rate, mobility index, Oxford stringency, weather.
  • Evaluation: Validation R² = 0.998, RMSE = 354.5, MAPE = 3.19%.
